# CS50P Problem Set Solutions

My solutions to [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/), psets 0–8.

These are self-study solutions, not submitted for any course credential. Each problem lives in its own folder, matching the course's structure.

These are written by hand and for reference only, did not go through Harvard CS50 official grader.
